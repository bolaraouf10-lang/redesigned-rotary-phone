# Chat App

بداية بسيطة لتطبيق شات لحظي يعمل على Cloudflare Workers.

## التشغيل
- ارفع `worker.js` إلى مستودع GitHub.
- اربط المستودع بـ Cloudflare Workers.
- افتح رابط الـWorker.
- اكتب اسمك وابدأ المحادثة.

هذه النسخة هي الأساس فقط. الحسابات وقاعدة البيانات والرسائل الصوتية ومكالمات الصوت والفيديو تحتاج إعدادات وخدمات إضافية قبل إضافتها.
